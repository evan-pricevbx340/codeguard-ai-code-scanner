## What CodeGuard AI Does

CodeGuard AI gives development teams an earlier way to identify privacy and security problems in their code. It is designed for DevSecOps processes that require quick feedback, policy-aware checks, and useful guidance for addressing findings before they advance through delivery.

The auditor examines source code and infrastructure files with an emphasis on enterprise security concerns. AI-assisted analysis, risk scoring, and reporting help developers, security teams, and compliance stakeholders understand possible GDPR, PII, and cloud security issues.

- Finds possible GDPR violations, exposed PII, and cloud security weaknesses in source code

## Using the Auditor

A common scan cycle looks like this:

1. Attach the repository or working tree you want to inspect.
2. Start a scan for source files or infrastructure definitions.
3. Open the dashboard and examine GDPR, PII, and cloud security findings.
4. Use the risk scores and report summaries to assess the results.
5. Apply suggested automatic fixes when they are appropriate.
6. Scan again to confirm the effect of the changes.

Common applications include:

- Checking a feature branch before it is merged
- Producing reports as part of compliance reviews
- Using remediation suggestions to shorten the path from finding to fix
